# Uthram Stores website

A responsive static website prototype for Uthram Stores, Meghamalhar Complex, Akkarapuram, Thrissur, Kerala.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling
- `script.js` — category filters, product search, mobile navigation and WhatsApp order list
- `assets/` — product photographs supplied for this project

## Run locally
Open `index.html` in a browser. For a local development server, use VS Code Live Server or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish free using GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `uthram-stores`.
2. Upload all files and the complete `assets` folder (keep the folder structure unchanged).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish. The live URL will be shown in the Pages settings, usually `https://YOUR-USERNAME.github.io/uthram-stores/`.
7. Test the URL on a phone and desktop.

## Before going live
- Confirm the owner approves the displayed contact number, email and address.
- Confirm delivery area and any delivery charges with the owner.
- Add actual prices only after the shop confirms them.
- Update stock/availability regularly. The current version intentionally asks customers to confirm current price and stock through WhatsApp.
- Check every image, phone link, WhatsApp link and Google Maps link after publishing.

## Important
This is a front-end catalogue and enquiry website. It does not process online payments, store orders in a database, or automatically sync live inventory. Customers send an enquiry/order list to the shop's WhatsApp number. Customers can attach a photo of a handwritten list in WhatsApp after opening the chat.
